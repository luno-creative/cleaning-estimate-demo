# ハウスクリーニング 見積もりデモ

## サービス概要

清掃メニュー・お部屋の広さ・汚れの状態・追加オプションを選択すると、ハウスクリーニングの概算料金を自動計算できるWeb見積もりデモです。

お客様が問い合わせ前に費用感や作業内容を把握できるようにし、事業者の見積もり対応を効率化するイメージを確認できます。

## デモサイト

https://luno-creative.github.io/cleaning-estimate-demo/

## 主な機能

- エアコン・キッチン・浴室・トイレ・水回りセット・空室清掃のメニュー選択
- お部屋の広さの選択
- 汚れの状態に応じた加算
- 換気扇・防カビ・窓清掃などの追加オプション
- 選択内容に応じた料金の自動計算
- 料金内訳と概算金額の表示
- 見積もり内容のコピー
- スマートフォン対応のレスポンシブデザイン

## 操作方法

1. デモサイトにアクセス
2. 清掃メニューを選択
3. お部屋の広さ・汚れの状態を選択
4. 必要な追加オプションを選択
5. 自動計算された概算料金と内訳を確認
6. 必要に応じて見積もり内容をコピー

## 使用技術

- HTML
- CSS
- JavaScript

## 制作目的

ハウスクリーニング事業者向けのWeb見積もりシステムのデモとして制作しました。

料金体系や追加作業を分かりやすく表示し、問い合わせ前の不安を減らすとともに、見積もり業務の効率化を提案することを目的としています。

## 注意事項

本サイトはLUNO CREATIVEの営業・提案用デモサイトです。

表示される料金やサービス内容は説明用のサンプルであり、実在する店舗・事業者の料金体系を示すものではありません。実際の料金は設備・汚れ・作業範囲などを確認したうえで決定される想定です。
