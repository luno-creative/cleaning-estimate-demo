# ハウスクリーニング料金見積もりシミュレーター

## 概要
ハウスクリーニングの概算料金を、ブラウザ上で簡単に計算できるWebアプリです。

## デモ
https://masanor.github.io/cleaning-estimate-demo/

## 主な機能
- 部屋数の選択
- 広さの選択
- オプションサービスの選択
- 合計金額の自動計算
- 料金内訳の表示
- 見積もり内容のコピー
- 入力内容のリセット
- スマートフォン対応のレスポンシブデザイン

## 使用技術
- HTML
- CSS
- JavaScript

## 制作について
HTML・CSS・JavaScriptを使用して制作した自主制作デモです。

表示される料金はサンプル用の仮設定です。実際のサービス料金ではありません。

実際の事業者様向けに、料金体系・デザイン・オプション内容などをカスタマイズできます。
